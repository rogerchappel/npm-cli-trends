# Security Policy

## Supported Versions

This repository publishes public npm metadata snapshots and local validation scripts. Security fixes apply to the current `main` branch.

## Reporting a Vulnerability

Please report suspected security issues privately through GitHub security advisories or by contacting the maintainer. Do not open a public issue for vulnerabilities.

Include:

- A short description of the issue.
- Steps to reproduce or inspect the affected artifact.
- Any known impact on generated data, scripts, or documentation.

The project does not store secrets or private registry data. If a generated artifact appears to contain sensitive information, treat it as a security issue and report it privately.
